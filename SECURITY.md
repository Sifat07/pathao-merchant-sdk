# Security Policy

## Supported versions

Only the latest release of `pathao-merchant-sdk` on npm gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: [Report a vulnerability](https://github.com/Sifat07/pathao-merchant-sdk/security/advisories/new).

Include what you found, the version, and steps to reproduce. This is a community project maintained by one person, so I can't promise a response time, but I will reply as soon as I can and credit you in the fix if you want.
